# HULAS Stainless Steel 304

Single-page tool to **measure, estimate and quote** stainless steel 304 products, made for fabricators working with Hulas Metal Crafts Ltd., Biratnagar, Nepal.

Live app: https://chrisnamishra.github.io/HULAS-Stainless-Steel-304/

## Features

- Measure SS 304 pipe and tube work (round, square, rectangular)
- Estimate weight and material cost
- Prepare a quote for the customer
- Installable on phone as an app (PWA) and works offline

## Files

| File | Purpose |
|---|---|
| index.html | The whole app (layout, styles and logic) |
| manifest.json | App name and icons for installing on a phone |
| sw.js | Service worker for offline use |
| icon-192.png, icon-512.png | App icons |

## How to use

1. Open the live app link on your phone or computer.
2. Enter the measurements of the job.
3. Check the estimate and share the quote.
4. On a phone, use "Add to Home screen" to install it.
